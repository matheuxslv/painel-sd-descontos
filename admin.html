Como publicar a atualização no painel público

  1. Importe os relatórios acima e confira o resumo de cada arquivo.
  2. Clique em Pré-visualizar painel para ver como ficará.
  3. Clique em Baixar dados.json.
  4. No GitHub, abra a pasta data do repositório, clique em Add file → Upload files, envie o dados.json baixado (ele substitui o anterior) e clique em Commit changes.
  5. Em 1 a 2 minutos o GitHub Pages publica a nova versão e o painel carrega os dados atualizados.

O arquivo publicado contém apenas os valores necessários ao painel (data, plataforma, valores, comissões, quantidade e status). Números de pedido são substituídos por códigos irreversíveis, e nomes de produtos, lojas e compradores não são incluídos. Os relatórios originais nunca são publicados.
